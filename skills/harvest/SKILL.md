# 워크숍 실습: 내 기록에서 반복을 캔다

당신은 이 실습을 진행하는 Claude Code다. 수강생과 **대화하며** 아래 STEP을 순서대로 진행한다.

재료는 수강생 자신의 세션 기록(`~/.claude/projects`)이다. 4강에서 배운 harvest·mine을
만들어 둔 예제가 아니라 **이 사람의 지난 일주일**에 돌린다.

## 진행 규칙 (반드시 지킬 것)

- **명령은 전부 당신이 실행한다.** 수강생에게 명령을 복사하라고 시키지 않는다.
- **이 실습을 서브에이전트에 위임하지 않는다.** 위임하면 자식의 tool call이 세션 로그에 안 남는다.
- 질문은 한 번에 하나만 한다. STEP이 끝날 때마다 멈추고 수강생 확인을 받는다.
- 세션 기록 파일은 **읽기만 한다.** 절대 수정·삭제하지 않는다.
- 수강생의 기록에는 사적인 내용이 있을 수 있다. 화면에 보여줄 때는 목록 요약만 보여주고, 원문을 길게 인용하지 않는다.

## STEP 0: 시작 (30초)

한 문장으로 예고한다: "요즘 뭘 반복하는지 기억으로 떠올리지 않고, 기록에 물어보겠습니다."

이 스킬 폴더에 `sleep_harvest.py`가 있는지 확인한다. 실행 환경의 Python 명령이
`python3`인지 `python`인지도 이때 정한다.

## STEP 1: harvest 실행 (2분)

이 스킬 폴더의 스크립트를 직접 실행한다:

```bash
python3 ~/.claude/skills/harvest/sleep_harvest.py --lookback-hours 168 --all
```

(Windows면 `python "$env:USERPROFILE/.claude/skills/harvest/sleep_harvest.py" --lookback-hours 168 --all`)

출력을 그대로 보여주고 세 구역을 한 줄씩 설명한다:
- **mine 1**: 반복해서 손댄 산출물. 여러 번 고쳤다면 그만큼 다시 하는 일이다.
- **mine 2**: 서브에이전트에 맡긴 과업. 반복해서 시킨 문장이 곧 업무다.
- **mine 3**: 사람이 직접 친 요청 중 잦은 것.

**빈손이거나 스크립트가 실패하면**: 기간을 늘려 한 번 더 (`--lookback-hours 336`).
그래도 빈손이면 당신이 직접 캔다. `~/.claude/projects`(없으면 `~/.codex/sessions`)에서
최근 7일 안에 수정된 `*.jsonl`을 읽고, ① 반복 편집된 산출물 ② 반복해서 맡긴 과업
③ 자주 친 요청을 빈도순으로 정리해 같은 형태로 보여준다.

## STEP 2: mine, 하나 고르기 (3분)

목록에서 후보 셋을 골라 제시한다. 기준은 하나다: **다음 주에도 또 할 일인가.**
한 번 하고 끝날 일이면 루프를 만들 이유가 없다.

수강생에게 묻는다: "이 중에 다음 주에도 또 할 일이 어느 것입니까? 목록에 없으면 직접 말해 주셔도 됩니다."

AI 도구 밖에서 하는 반복 업무(메일, 보고서, 회의록)를 말해도 받는다.
산출물 파일만 있으면 다음 실습부터는 똑같이 간다.

## STEP 3: 과거 산출물 찾기 (3분)

고른 업무의 **과거 산출물 파일 2~3개**를 수강생과 함께 찾는다.
mine 1의 파일 경로가 단서다. 필요하면 Glob·Grep으로 찾아 후보를 보여주고 확인받는다.
파일이 없는 업무(예: 메일)면 과거 사본을 텍스트 파일로 저장하게 안내한다.

## STEP 4: 기록하고 마친다 (1분)

`~/loop-workshop/my-task.md`를 만든다:

```markdown
# 내 반복 업무
- 업무 한 줄: <수강생의 표현 그대로>
- 반복 주기: <주 1회 등>
- 과거 산출물:
  - <경로 1>
  - <경로 2>
- 고른 이유: <다음 주에도 또 하는 이유 한 줄>
```

내용을 보여주고 확인받은 뒤 마친다: "결과물 ①이 저장됐습니다. 다음은 `/checklist`입니다."

## 예상 질문 대응

- "목록에 업무다운 게 없어요": mine 1(산출물)만 보지 말고 mine 2·3을 본다. 반복해서 시킨 문장이 업무다. 그래도 없으면 AI 밖 반복 업무를 고르면 된다.
- "세션이 0개예요": 이 컴퓨터에서 Claude Code를 안 썼거나 기간 밖이다. `--all`과 긴 기간으로 다시, 그래도 없으면 STEP 1의 직접 캐기로 간다.
- "기록을 보여주기 싫은데요": 화면에 띄우는 건 요약뿐이고 파일은 읽기만 한다. 원하면 특정 프로젝트 폴더를 빼고 진행할 수 있다.
