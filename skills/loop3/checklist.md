# postmortem 채점표 (5점 만점, 1항목 1점)

| # | 기준 | 확인 방법 |
|---|---|---|
| 1 | 장애 시작과 복구 시각이 분 단위로 있다 | 시작 14:20 전후, 복구는 14:52 롤백 또는 15:10 정상화 |
| 2 | 근본 원인에 배포와 설정값이 둘 다 있다 | v2.3.1 배포 + `db_pool_size` 50→10 |
| 3 | 영향 수치가 1개 이상 있다 | p95 최고 2500ms 또는 err rate 최고 9.8% |
| 4 | 로그 근거가 행 번호로 인용된다 | 예: `app.log 7행`. 7행(pool exhausted)·3행(배포)·17행(롤백) 중 아무거나 |
| 5 | 재발 방지 액션이 2개 이상, 담당과 함께 있다 | 예: "canary 없는 직배포 금지 (담당: deployer 팀)" |
